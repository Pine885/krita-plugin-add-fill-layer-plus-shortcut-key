# Fill Layer Plus

A small Krita plugin that creates a color Fill Layer using the current
foreground color without opening the Fill Layer dialog.

## Installation

1. Download `fill-layer-plus.zip`.
2. In Krita, go to **Tools -> Scripts -> Import Python Plugin from File...**
   and select the zip.
3. Restart Krita.
4. Go to **Settings -> Configure Krita -> Python Plugin Manager**, enable
   **Fill Layer Plus**, and click **OK**.
5. Restart Krita again.
